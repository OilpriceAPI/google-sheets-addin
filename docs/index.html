REFERENCE IMPLEMENTATION

OilPriceAPI for Google Sheets

Source-timestamped API records through manually installed Google Apps Script formulas and sheet actions.

Publication status

This project is not currently published in the Google Workspace Marketplace. Install it only by reviewing and copying the tagged source into a test spreadsheet's Apps Script project.

First formula

=OILPRICE("WTI_USD")

The formula returns the numeric value from the latest available source record. The batch action writes its currency, unit, source label, source timestamp, and retrieval timestamp to a `Data` sheet.

Runtime behavior

SurfaceBehavior
Latest priceFive-minute user cache; strict price, currency, unit, and timestamp validation.
HistoryVersioned lookback endpoint; source timestamp and price rows; one-hour user cache.
